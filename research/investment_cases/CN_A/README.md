# CN_A Investment Cases

This namespace contains mainland China A-share security-level investment cases.

## Scope

- SSE main board / STAR Market
- SZSE main board / ChiNext
- Beijing Stock Exchange

Use the exchange-qualified ticker in structured records (`300602.SZ`, `688xxx.SH`, `920xxx.BJ`). Directory names use the numeric ticker for stable paths.

Do not place Hong Kong-listed shares, U.S.-listed ADR/ADS, or unlisted private companies in this namespace. Cross-market or private-company evidence can be linked into an A-share case when it is decision-relevant, but the listed security remains the unit of valuation and action.
