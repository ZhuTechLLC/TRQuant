## Important audit findings

### 1. TSM should not be reworked again
The TSM decision-grade candidate review already passes primary-source coverage, PIT integrity, metric classification, historical valuation reproducibility, dominant-variable analysis, market expectations, counter-evidence, and sizing/exit separation. Repeating more research before recording the approval decision would be process drift.

### 2. Negative cases are valuable, but source hygiene still matters
This review explicitly tested whether `AVOID` cases could be promoted first because zero capital can be a legitimate decision-grade outcome.

The answer is **yes in principle, not yet for the current two strongest counterexamples**:
- 飞龙: the avoid logic is economically persuasive, but the evidence ledger still needs canonical source/date cleanup.
- 日发: the audit/profitability gate is persuasive, but the annual-report evidence needs canonical filing reconciliation and a valid availability date.

This prevents a lower evidence standard for bearish conclusions than for bullish conclusions.

### 3. Imminent events are genuine blockers, not procrastination
For NVDA, Lingyi, UBTECH, Leadshine and the joint liquid-cooling cases, waiting a few days is evidence-based because scheduled results can directly change revenue, margin, cash and valuation inputs. This is different from undefined demands for “more confirmation.”

### 4. Commercialization evidence remains the largest A-share gap
Across the robot/liquid-cooling cohort, the most common missing bridge is:

`named customer / batch claim -> standalone revenue -> margin -> cash conversion -> EPS revision`

Until that bridge is visible, supplier purity or technology capability should not trigger decision-grade promotion.

## Skill-evolution decision from this review

### Supported cross-case lesson — promote within the case-learning layer
**Supplier evidence must be staged by economic conversion:**

`capability -> named design-in/cooperation -> validation -> small batch -> stable batch -> material revenue -> margin -> CFO/FCF -> EPS revision`

This is supported across materially different robotics/liquid-cooling cases and is consistent with the existing financial-metric ontology. It should guide future supplier research by default.

### Do not duplicate existing core rules
The following findings are already substantially covered by the existing Equity Investment Case principles and therefore should **not** create redundant new core rules:
- theme/business quality is not security attractiveness;
- orders/backlog/revenue are not shareholder cash flow;
- valuation must bridge price to required operating outcomes;
- no-action is a valid decision;
- events trigger re-underwriting rather than automatic trades.

### Remain candidate-level
- robot BOM evidence should be keyed by model/year/component;
- ownership-adjusted value capture for listed parents/subsidiaries;
- identical operating company can justify different A/H security actions;
- active cooling convergence across AI compute and humanoid robotics as a cross-theme opportunity map.

These need more cross-sector/cross-market counterexamples before promotion to a core Skill rule.
