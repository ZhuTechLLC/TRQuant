# M6.2-P2E Expansion Manifest Schema v0.1

Status: **FROZEN BEFORE CANDIDATE DISCOVERY COMPLETES**  
Date: 2026-08-24

This schema defines the only fields permitted in P2E candidate construction, mechanical eligibility and PIT provenance before any post-entry outcome extraction.

## 1. Identity fields

- `expansion_id`
- `category` (`E1`..`E5`)
- `ticker`
- `company_name`
- `calendar_year`
- `first_public_date`
- `first_public_time_et`
- `source_type`
- `primary_source_url_or_identifier`
- `primary_source_document_date`
- `primary_source_clock_time_if_available`
- `canonical_selection_string`
- `selection_sha256`
- `category_year_hash_rank`

## 2. Event-definition fields

- `event_title`
- `event_definition_short`
- `category_rule_matched`
- `discovery_term_or_form_item`
- `sec_form_type_if_applicable`
- `sec_item_if_applicable`
- `government_or_regulator_if_applicable`

No subjective `catalyst_strength`, `expected_return`, `semantic_complexity`, `quality_score`, or recommendation field is allowed.

## 3. Decision-time fields

- `session_classification`
- `verified_public_availability_et`
- `decision_rule_applied`
- `frozen_decision_time_et`
- `timestamp_evidence_mode`
- `source_grade`

## 4. Pre-outcome audit fields

- `pilot_duplicate_flag`
- `combined_ticker_event_count_before_admission`
- `ticker_cap_pass`
- `material_concurrent_catalyst_flag`
- `confounder_notes`
- `mechanical_price_observation`
- `prior20_median_daily_dollar_volume`
- `mechanical_status`
- `mechanical_reason`
- `pit_status`
- `pit_reason`
- `primary_outcome_eligible`

## 5. Forbidden fields before manifest freeze

The candidate/provenance artifact must not contain:

- T+1/T+3/T+5 return;
- SPY-excess return;
- MFE/MAE;
- win/loss;
- post-event RVOL;
- analyst-revision response;
- realized volatility after the event;
- options response;
- later company outcome;
- strategy PnL;
- any post-event ranking field.

## 6. Selection audit

For each of the 25 category-year cells, persist:

- total source-defined population count;
- population IDs or source identifiers;
- exclusions before hashing with exact reason;
- hash-ranked order;
- the five admitted candidates or `SOURCE_POPULATION_SHORTFALL`;
- ticker-cap skips;
- duplicate skips.

The manifest is frozen before mechanical/PIT outcome extraction is joined to any return data.
